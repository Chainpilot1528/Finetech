# Glossary

Use these words in code, the API, the UI and tickets.

| Term | Meaning |
|---|---|
| Partner | An organisation that sources loans. The tenant. |
| Channel | The partner's trading name. |
| User | A person who signs in. Belongs to one partner, or none if internal staff. |
| Reference ID | The partner's human-readable code. |
| Case | One loan application. Never "lead" or "file". |
| Case type | Open Market (ops runs it) or In-House (partner runs it). |
| Relook | A case sent back to the partner for more information. |
| Disbursal | One payout on a case, with a UTR. A case can have several. |
| Rate card | Commission rates by lender, product, loan type and slab. |
| Invoice | A partner's commission claim for one disbursal. |
